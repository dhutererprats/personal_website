# Earth Texture

`earth-blue-marble-2048.jpg` is an unmodified 2048 x 1024 NASA Blue Marble mosaic
(266,599 bytes), served locally for fast, reliable globe rendering. It is a
historical surface mosaic, not live weather or current cloud cover.

Source: https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57730/land_ocean_ice_2048.jpg
Background: https://science.nasa.gov/resource/blue-marble/
Credit: NASA Goddard Space Flight Center. Image by Reto Stockli; enhancements
by Robert Simmon, with data support from the MODIS teams.
Usage guidance: https://www.nasa.gov/nasa-brand-center/images-and-media/
